# PALINODE — prologue and Floor I

Unity 6 (6000.5.10f1), URP 2D Renderer, Input System, TextMeshPro.

## Run
1. Open `E:\UnityHub\Projects\PALINODE` in Unity Hub.
2. Open `Assets/_Game/Prologue/Scenes/Menu.unity`, press Play → **New Game**.
   Any prologue scene can also be played directly (it starts at its first chapter).

Controls: WASD / arrows / left stick — walk; **E** / gamepad A — interact;
hold **Esc** or **Space** for 1.5 s — skip the current scene.
Debug (Editor / Development build): **F1** chapter list (then 1–8, 0 = menu), **F2** speed ×4, **F3** show colliders.

## Rebuild (batch mode)
```
"C:\Program Files\Unity\Hub\Editor\6000.5.10f1\Editor\Unity.exe" -batchmode -quit -projectPath "E:\UnityHub\Projects\PALINODE" -executeMethod Palinode.Editor.ProjectBuilder.BuildEverything -logFile "E:\UnityHub\Projects\PALINODE\build.log"
```
Or in the editor: **Tools → PALINODE → Build Everything**. Idempotent; exit code 0/1 in batch mode.
It imports TMP essentials, sets up URP + post-processing, processes art (background removal, slicing),
applies import settings, creates font assets, the runtime registry (`Assets/_Game/Resources/PalinodeConfig.asset`),
all scenes, build settings and player settings, then validates `prologue.json`.

Tests: `-runTests -testPlatform EditMode` / `PlayMode`. The PlayMode smoke test plays the whole prologue at ×10
with an autopilot and writes screenshots to `Screenshots/`. Environment variables: `PALINODE_TEST_LANG=RU`,
`PALINODE_TEST_SPEED`, `PALINODE_TEST_FROM` / `PALINODE_TEST_TO` (chapter ids, e.g. `scene4`).
Markers named `seq_<name>|crop=x,y,w,h|n=12|dt=0.08` capture an animation contact sheet (frames exactly `dt` s of game time apart).
`HandwritingSamplesTest` renders the manuscript page with each handwriting font in EN/RU (`Screenshots/Fonts_*.png`).
Background-removal control sheets (black / white / magenta + edge zooms): **Tools → PALINODE → Art Check Sheets**
(`-executeMethod Palinode.Editor.ArtCheckSheets.GenerateBatch`) → `Screenshots/ArtCheck/`.

## Floor I "The Press"
After REVISION 01 the prologue loads `Assets/_Game/Floor1/Scenes/Floor1.unity` (it can also be played directly).
Death starts a new run straight in the first room of Floor I; the prologue only plays on **New Game**.

Controls: WASD / left stick — walk; arrows / right stick — ink (4 directions, last pressed wins); **Space** / RB — red pencil;
**E** / A — take, buy, go down; **Tab** / Select — contents (full map); **Esc** / Start — pause (revision number, original pages).
Debug (Editor / Development build): **F4** on the floor → 1 invulnerable, 2 kill the room, 3 teleport to the boss, 4 whole map,
5 give the next item, 6/7 revision ±1, 8 reset the meta save, 9 auto-kill; **F1** in the prologue lists "Floor I (skip the prologue)".

## Layout
- `Assets/_Game/Scripts/{Core,Cutscene,Gameplay,Localization,Audio,UI,Effects}` — runtime (`Palinode.Runtime`)
- `Assets/_Game/Scripts/Floor/{Generation,Core,World,Actors,Combat,Enemies,Boss,Items,UI}` — Floor I (`Palinode.Floor`);
  generation, rooms, doors, camera, shots and health adapted from `RogueDungeon`
- `Assets/_Game/Floor1/{Art,Audio,Data,Scenes}` — Floor I assets and data
- `Assets/_Game/Editor` — builder, art processor, render/font setup (`Palinode.Editor`)
- `Assets/_Game/Tests/{EditMode,PlayMode}`
- `Assets/_Game/Shaders` — Imprint (full-screen), RainGlass, Fog, particles, additive glow
- `Assets/_Game/Fonts` — Bad Script (handwriting), Marck Script, Caveat, PT Mono, Cormorant Garamond (+ OFL licences)
- `Backups/<date>/` — copies of `Assets/_Game` taken before larger changes (no git on this machine)
- `Assets/_Game/Prologue/Art/Processed` — generated transparent / sliced sprites (do not edit by hand)
